    Configuración

    • Guía rápida: el botón ☰ oculta el panel izquierdo; el menú cambia de sección; los recursos abren paneles laterales, superior o inferior; las tarjetas de módulo abren un panel superior con acciones.
    • Herramientas: la barra inferior permite avanzar diapositivas, cronometrar, usar puntero láser, lápiz, zoom, pantalla negra y pantalla completa. Atajos: ← →, B (pantalla negra), Esc (cerrar).
    • Límites conocidos: la foto del encabezado está recreada con formas CSS, no es la imagen original; los textos de módulos y recursos son de ejemplo; el avance inicial (3 de 8) y las cifras 125 / 92 % son datos de muestra; el tema claro es una aproximación; la pantalla completa puede estar bloqueada dentro de algunos visores.
